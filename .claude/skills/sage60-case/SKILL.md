# sage60 ケース設計

ここには構造・判断の理由・ルールだけを書く。**数値の正はコード**で、ここと食い違ったらコードに従う。

| 知りたいこと | 場所 |
|---|---|
| 作り方・コマンド・一回限りのスクリプト | `case/README.md` |
| 平面の数値 | `case/casegeo.py`、`case/make_right.py` の先頭 |
| 高さ・穴径（Fusion のパラメータ） | `case/fusion/stage0.py`（ロープロは `LP_PARAMS`） |
| トラックボールケース | `case/trackball/README.md` |
| ギャラリー・検証結果・宿題 | https://claude.ai/artifact/83ajHmoQUSwifZzPSDxWLz |

Fusion 操作は `fusion-mcp` スキル。ドキュメントは Admin Project の `sage60_{left,right}_bottom`（MX）と `sage60_lp_{left,right}`。1ドキュメントに下ケース＋上ケース `MOCK_A`（A案で確定。スカートを机まで下ろし、下端も傾斜で切る）＋カバーが入る。

## ルール
- **CNC が最優先**（ユーザー「CNC の指摘は徹底的に直す」）。試作は3Dプリント、本番は JLCCNC。[ガイドライン](https://jlccnc.com/help/article/CNC-Machining-Design-Guideline)
  - 縦の内角 R ≥ H/10 + 0.5（`casegeo.cnc_r`）、壁 0.8mm 以上（`THIN`）、アンダーカット無し。
  - 段取りは2回。下ケースは「上からプレート面に垂直」「下から机の面に垂直」、上ケースは上下ともプレート面に垂直。
  - 検証は `fusion/machinability.py`。4ドキュメントとも全項目0（`cnc_<side><sfx>.json`）にする。
- 形は Python が計算し、Fusion で作り直す。stage0 がドキュメントを空にするので、Fusion 上の手直しは消える。直すならスクリプトを直す。
- 座標：プレート上面 z=0、Fusion の y＝−KiCad の y。平面形状は Python、高さと穴径は Fusion のパラメータ。
- 形を変えたら `fusion/check.py`・`check_parts.py`・`machinability.py` を流し、全部0にする。
- 画像は必ず PCB・部品・スイッチ・キーキャップを入れて撮る（stage5 の `PCB_REF`。stage0 で消えるので毎回実行）。Python の図にも PCB・プレートの外形を描く。添付できないときは Mac で `open` する。
- 段階ごとにスクリーンショットでユーザーに確認を取ってから次へ進む。
- 構造やルールが変わったら、このスキルと Artifact を更新する（画像は `fusion/shots.py`）。

## MX とロープロの違い
同じ PCB（MX/Choc 両対応）とプレート（どちらも 1.2mm）。構造は同じで数値だけ変える。ロープロの方針は「とにかく薄く、余白と隙間を詰める」。

| | MX | ロープロ |
|---|---|---|
| スイッチ | Cherry MX | Kailh Choc v2（画像は v1 のモデルで代用） |
| 傾斜 `tilt` | 7° | 0°（ユーザー決定） |
| PCB 上面 | −5.0 | −2.2 |
| 天面 `top_h` | +7 | +2.0 |
| 床 | `cav_z` 11 で水平、バッテリーの所だけ `bat_z` 14.4 | 空洞全体がバッテリーの深さ `cav_z` 11.6 |
| MCU 部 | 外壁の上端を `mcu_cover_z` 3.9 まで下げる（`TOP_MCU_SKIRT`） | 天面より高い台 `mcu_cover_z` 4.8（`TOP_MCU_BLOCK`） |
| カバー厚 `cover_t` | 3.0（天面より 0.1 低い） | 2.5（上面 +7.3） |
| 磁石穴 上／下 | 3.1 / 3.1 | 2.1 / 4.1（上の磁石が 0.9 突き出て位置決めを兼ねる。リングが 3.2 しかないため） |
| ガスケット | 1.5（仮） | 1 を 0.8 に潰す |
| トラックボール座面 `TB_SEAT` | −9.0 | −6.2 |

ロープロで見送った案：XIAO を PCB 裏へ移す。USB を上が開いた切り欠きにする（「微妙」とのことで MCU 部の台に変更）。

## 全体の構造
左右分割。右＝左を x=122.92 で反転（x' = 245.84 − x）＋トラックボールの差分。傾斜軸の線だけは反転しない。

- **被せ式**：上ケースは下ケースごと上から被さり、一回り大きい。ベゼル約5.3mm（ユーザーの実物レビューで約10mm から縮小）。外形＝本体＋`CASE_OFF`、外壁 `wall`、開口＝本体＋`open_clr`。
- **傾斜**：内部はプレート面基準で作り、底面だけ `tilt` で切る。
- **ガスケットマウント**：プレートのタブ（3.4mm）を下ケースの棚と上ケース外壁内側の段差で上下から挟む。
  - 段差は外壁と一体の肉厚部にする（独立した突起にしない。強度とCNCのため）。下ケースの窪みは外周側が開いたL字の棚。
  - 溝はタブの先端の幅＋0.6（最低17）。下 `GASKET_POCKET` は外壁の外まで抜き、上 `TOP_GASKET_SLOT` はリングの中で止める。角 R1。
  - 上下の合わせ面は `shelf_d`（プレート下面）。
- **磁石**：φ6×3（ダイソー）で上ケースのリング下面と下ケースの棚を向かい合わせ、左右各4か所（`N_MAG`）。上下で極性を揃える。壁 `MAG_WALL` 0.8。
  - 左：奥2、親指の段差 `MAG_STEP`（足りない分は外形を直線で出す `magnet_bump`）、右下の切り欠き `MAG_NOTCH`。
  - 右：左の辺 `MAG_A2`（右 PCB の切り欠き）、右手前 `MAG_B`（外形を出す。ユーザー了承）、奥2（自動。`fps(fixed=)`）。
  - PCB・プレートの切り欠きは適用済み（`oneshot/mag_notch.py`、`notch_fillet.py`）。
- **プレートは左右別**（ユーザー決定。共通プレートは切り離しが現実的でなかった）。外形の元は `production/plate/mx_{left,right}_plate.dxf`（KiCad のプレート基板は 2026-11-01 に削除）。

## 部位ごとの決定
- **外形**：奥は左右の奥の角を通る1本の円弧。上ケース外壁の凸の角は `WALL_OUT_R` 2.5（ユーザー決定。市販アルミケースの実測 R2〜3。外側の角は CNC の制約が無いので内側と切り離した）。内側の角は `OUTER_R`・`CONCAVE_R`。天面の外周に 0.5 の面取り `TOP_CHAMFER`（MCU カバーの下は除く）。
- **内壁**：下ケースの空洞と上ケースのリング内側は同じ形（`inner_outline`＝PCB＋0.3 とプレート本体＋`open_clr` の和）。`CAVITY` はそれに深さに応じたドッグボーン（`relieve`）を足す。逃げはリングの下に隠れる。磁石の柱には当てない（`forbid`）。空洞側に Fusion のフィレットは付けない（上下で食い違うため）。
- **床**（ユーザー指示「MX の床は水平、バッテリーの所以外は埋めてよい。吸音フォームは薄いので水平が良い」）：ソケットの下にフォーム用 2.6mm。バッテリー EEMB 552036（5.5×20×36）は JST の左に横向き（`battery_pocket`）。PCB はガスケットで浮かせるので支柱は無し。
- **ゴム足**：φ10、机側の四隅に凹み（`foot_d`、`foot_t`）。
- **USB**（参考品と同じくレセプタクルが面一）：外から差込口の面（XIAO の基板端＋1.5）まで、成形部用の上が開いた溝 `USB_RECESS`。差込口の面に壁 1.2 を残してレセプタクルの穴 `USB_RCPT`。上は MCU カバーが閉じる。成形部は 12.5×7 まで通す。`xiao_t` 1.4 は Seeed の STEP での実測値。
- **スライドスイッチ**：3ピン THT 2.54mm（ユーザー決定。MSK-12C01 は本体が XIAO と重なるのでやめた）。つまみは外壁側を向く。指の凹み `SW_SCOOP` とつまみまでの穴 `SW_OPEN` を、平面スケッチから上へ切る溝にする（上ケースは凹みだけ）。凹みはつまみより +y に 1mm（`SW_SCOOP_Y`、薄肉回避）。
- **MCU 部**：アンテナのため上ケースで覆わない。リングを切る `TOP_MCU_OPEN` の付け根は `TOP_MCU_FILLET`、下ケースの壁 `MCU_RING` はそれと同心で `clr` 内側。
- **MCU カバー**：ウォルナット、発注は DXF（`mcu_cover_dxf.py`）。形は B 案（ユーザー決定）：開口から外壁の外面まで覆う。内側の辺はキーキャップ＋`KEY_CLR` を避ける。
  - 磁石1個で留める（ユーザー決定。M2 タップはいずれバカになるのでネジをやめた）。φ6×3 を上ケースの保持部 `MCU_MAG_BOSS` に入れ、カバー裏に φ8×0.5 の鉄の円板（`disc_d`、`disc_t`）。下ケースの壁だけでは幅が足りないので、上下の幅を上ケースにまとめ、下は `MCU_MAG_CUT` で逃がす。ロープロは穴を貫通させて接着（XIAO のシールドに当たるため）。
- **ガード**（`guard_region`、`guard_fill`）：上ケースで、メインブロックと親指の間・右列の下・右の壁沿いを塞ぐ。`guard_z` でプレートから浮かせる（ガスケットで動くため）。R1.5 の工具が届かない所もガードにする。幅 3mm 未満の帯は作らない（`GUARD_MIN`）。上ケースにつながらない島も作らない。

## 右（トラックボール）
- PCB・プレートの差分：プレートは手前 x100〜189 が無くタブ5つ。PCB には J1 用の舌がある。`pcb/mx/right/`。
- **トラックボールケース**：`trackball/trackballcase_low.stl`（roBa 由来の改造版）。回転しない。ボール中心は `tb.py` の `TBX, TBY`。
- **固定**：磁石2個（ユーザー決定。机側からの M1.7 ネジをやめた）。ケースの耳に φ6×3 を埋め込み、下ケースの `TB_MAGS` と引き合う向きで向かい合わせる。横は `TB_POCKET` で決まる。**支持球は非磁性（セラミック/ジルコニア）にする**。
- **外形**（ユーザー「余白はできるだけ無くしたい」「トラックボールまわりはシンプルに」）：反転した左の外形＋トラックボールの包絡線＋PCB＋3。親指とトラックボールの間の凹みは直線で埋め、x≥`HULL_X0` の手前は1つの凸包。下ケースの壁 `THIN_BOT` 2、上ケース `THIN_TOP` 3 未満の部分は `make_right.py` が自動で削る。
- **開口**：キーの穴とトラックボールの穴の2ループ。別々に丸める（まとめるとセンサーの筒がくびれで切れる）。
- **ボールの奥**：`TB_ACCESS` で上ケースを全部削り、下ケースは `TB_DECK` まで下げる。PCB の縁が見えるのはユーザー了承済み（覆うと 2〜4mm の細い帯になる）。`RIM` は親指脇の縁を 3mm 以上残す値。
- **ボールの手前**（ユーザー「枠は残し、被っている上だけ若干削る」「親指とトラックボールの間の三角形が邪魔」）：ケースで囲い、天面を `tb_front_drop` 下げる（`TB_FRONT_LOW`、stage4）。範囲の端は外壁に直角に切り、くさびを作らない。
- **J1**（センサー基板とのコネクタ）：L字コンスルーが売り切れたので変更（ユーザー決定）。
  - センサー基板の +x 面に丸ピンソケット 6604S（秋月 g100241 の1×20を7本に切る）。FH-1x7SG/RH は大きすぎて却下。
  - PCB に細ピン L字ヘッダ PHA-1x40RG（秋月 g106363）。ピンを 2.5 に切り、ハウジングをソケットに突き当てる（「ピンが見えるのはダサい」）。センサー基板の x はコネクタで決まる。
  - センサー基板の下端は `TB_SEAT` に来る。溝は掘らない（脚の下を削るため）。
  - 組み立て順：下ケース → PCB とプレート → センサー基板を差す → 上ケース・トラックボールケース。
  - `J1_REF`（stage6）で干渉を見る。ロープロは `J1_RELIEF` で逃がす。

## PCB を編集するとき
`oneshot/` は適用済みで、再実行すると二重に入る（`case/README.md`）。配線を変えたら `kicad-cli pcb drc --refill-zones --save-board` で DRC の件数が変更前と同じ・未配線0を確認する。プレートの発注は Edge.Cuts だけ（1.2mm 指定）。

## 未決事項
- ガスケット厚（MX は仮 1.5）、クリアランスの確定値。
- Choc v2 の取付高さ 2.2 は v1 と同じと仮定（未実測）。
- スライドスイッチの開口の高さ `SW_ZC`（部品が決まったらつまみに合わせる）。
- MCU カバーは外壁側をひねると回る。気になればピンを足す。
