# sage60 ケース設計

Fusion操作は `fusion-mcp` スキル（http://127.0.0.1:27182/mcp）を使う。ドキュメントはすべて Fusion「Admin Project」。
設計資料（MX／ロープロのギャラリー＋数値・検証・宿題）: https://claude.ai/artifact/83ajHmoQUSwifZzPSDxWLz （構造を変えたらこのArtifactも更新する。画像は `fusion/shots.py` で4つのドキュメントから同じ8方向で撮る。手前・奥・側面は固定縮尺）

## 構造（確定）
- 左右分割。基本は左右ミラー（x=0）だが、右手側にトラックボールがあるので右は若干アシンメトリー。
- ガスケットマウント：プレートのタブを「下ケースの棚」と「上ケース外壁内側の段差」でガスケット越しに上下から挟む。
  - 段差は外壁と一体の肉厚部にする（外壁から独立した突起にしない。強度とCNCのため）。
  - 下ケースの窪みは外周側を開放したL字の棚にする。
  - タブの上下にガスケットが入るので、その分の隙間を確保する。
- 上下ケースの固定はネオジム磁石 φ6×3（ダイソー、2026-10-03 ユーザー決定・厚さ確認済み。φ2×2 は手に入りにくいため）。上ケースのリング下面 ↔ 下ケース棚の上面に向かい合わせで、左右各4か所（`N_MAG`。配置は「CNC 対応」の節）。上下で極性を揃える。穴は `mag_d` 6.1、周りの壁 `MAG_WALL` 0.6。深さは `mag_t` 3 から：上 `mag_h_top`＝mag_t+0.1、下 `mag_h`＝2·mag_t−mag_h_top+0.2（MX は上下とも 3.1）。ロープロは上ケースのリングが3.2mmしかないので `mag_h_top` 2.1、上の磁石が0.9mm 下に突き出して下の穴（4.1）に入る（位置決めピンを兼ねる）。左は奥2・親指の段差（`STEP_FILL` で外形の凹みを埋めた所）・右下の切り欠き（`MAG_NOTCH` (187.06,−105.78)、固定）。右は自動で奥2・手前左・右下。
- 下ケースは一部空洞にする（バッテリー、吸音フォーム、カウンターウエイトを入れるため）。
- 上ケースは下ケースごと上から被せる形なので、下ケースより一回り大きい。キースイッチとキーキャップ（ストローク込み）に干渉しない開口を開ける。
- 傾斜は5°（旧 sage60-top-case は7°）。
  - 傾斜は下ケースでつける。内部形状はプレート面を基準に作り、底面だけを傾斜角で切る。
  - 角度はユーザーパラメータにする。
- USB-Cの開口が必要。
- マイコン（XIAO nRF52840）の位置は上ケースで覆わない。その部分はプレートを上からネジ止めする形にして、無線アンテナが外に出られるようにする。
  - 基板外形とマイコン・USB-Cの位置は KiCad から取る。
    - 左：`pcb/mx_main/mx.kicad_pcb`、プレートは `pcb/mx_left_plate/`
    - 右：`pcb/mx_right_tb/`、プレートは `pcb/mx_right_tb_plate/`

- 決定事項（2026-10-02 の実物レビュー後。左右とも `mechanical/case/` のスクリプトで作り直した）：
  - ベゼル（上ケース天面の幅）は約5.3mm（前は約10.3mm）。外形＝PCB/プレート本体＋4mm（`CASE_OFF`）、外壁 `wall` 2mm、開口は本体＋`open_clr` 1mm。そのためプレートのタブを 5→2.5mm に短くした（KiCad の `pcb/mx_left_plate/mx_left_plate.kicad_pcb`（旧 `mx_plate`）と `pcb/mx_right_tb_plate/mx_right_tb_plate.kicad_pcb` を `shorten_tabs.py` で編集済み。`gasket_v1/` は旧版で未変更）。2026-10-09 にガスケットを貼る幅が足りないので 2.5→3.4mm に伸ばした（`shorten_tabs.py ... -0.9 1.2`、両プレートに適用済み。MX・ロープロで同じプレートなのでロープロの上ケース外壁の内面（本体＋3.7）まで 0.3、MX は 0.9。リングの下に入る幅は MX 1.5→2.4、ロープロ 2.0→2.9mm）。
  - 外形の平面の角は R2（`OUTER_R`。スケッチで丸めているので、外形フィレットのフィーチャーは無い）。上ケース外壁の角は R4.3 になる。
  - 奥側の辺は、左右の奥の角を通る1本の円弧（左：R≈263）。USB は参考品（レセプタクルが面一）と同じ形（2026-10-02）：外から差込口の面（y=−27.05、XIAO の基板の端から1.5mm先）まで、成形部用の角丸の凹み 15×9 R2（x-z 面のスケッチ `USB_TUNNEL` を y 方向に押し出し、下ケースと上ケースの外壁を貫通）。差込口の面には空洞との間の壁（1.2mm）を残し、レセプタクル用の角丸の穴 9.8×4.0 R1.6（`USB_RCPT`）だけを開ける。四方とも閉じた穴にするため、MCU部の壁の上面 `mcu_cover_z` を 0→3.5→3.9mm に上げた（凹みの上に1.4mm の肉。MCUカバーの下面も z=3.9 になる。0 のままだとケーブルの成形部の上端がカバーに当たっていた）。XIAO の高さ `xiao_t`（PCB上面〜XIAO上面）は 1.4（基板1.2＋はんだで0.17浮く。Seeed の STEP を載せて確認。1.0 だとレセプタクルが穴の上端に0.05mm 当たっていた。2026-10-03）。成形部は 12.5×7 程度まで（チェック済み）。
  - 内壁は上下で1本（2026-10-02）：下ケースの空洞と上ケースのリングの内側は同じスケッチ形状（`casegeo.inner_outline`＝「PCB外形＋0.3（凸の角は尖らせ、凹の角はPCBのRに沿わせる）」と「プレート本体＋`open_clr`」の和を、固体側の内角がR1.5になるように丸めたもの。PCBから0.3未満になる所だけPCB＋0.3を優先）。左は CAVITY と TOP_RING_INNER が同じ曲線。右はトラックボールの穴の部分だけ上ケースが広い。空洞側には Fusion のフィレットを付けない（上ケースと食い違うため）。MCU部も奥へ広げない。
  - MCUカバーは磁石1個で留める（2026-10-24 ユーザー決定。M2 タップはいずれバカになるのでネジをやめた）。磁石はケース本体と同じ φ6×3 で、上ケースの外壁から内側へ張り出した保持部（`MCU_MAG_BOSS`、XIAO の USB 側の端の上）に入れる。中心は左 `MCU_MAG` (190.34,−33.5)、右は鏡像。下ケースの MCU の壁だけでは幅 3.7mm で φ3 までしか入らないため、上下の幅（約6mm）を上ケースにまとめた。下ケースは保持部の下を `MCU_MAG_CUT`（保持部＋clr と、帯の幅＋R を外形まで抜いた四角、角 R1）で `mcu_cover_z − mcu_mag_h − mcu_mag_floor − clr` まで下げる。穴の深さ `mcu_mag_h`＝mag_t+0.1、下の肉 `mcu_mag_floor` 0.8（ロープロは 0＝貫通で接着。0.8 だと保持部の下面 +0.9 が XIAO のシールドの上面 +1.27 に当たる）。カバーの裏には φ8×0.5 の鉄の円板を入れる凹み（`disc_d` 8.2、`disc_t` 0.6、スケッチ `MCU_DISC`）。保持部の付け根は R1.5（`casegeo.mcu_magnet_boss`）。磁石1個なので外壁側をひねると回る（気になればピンを足す。未定）。
  - スライドスイッチ（2026-10-02、指で操作できるように拡大）：外壁に指を入れる角丸の凹み `SW_SCOOP` 16×10 R4（y×z、中心 z −4.3）を外面から x=193（空洞の壁から1.6mm手前）まで、その奥はつまみまで抜ける角丸の穴 `SW_OPEN` 12×6 R1.5。どちらも y-z 面のスケッチ（平面 `SW_FLOOR`）を x 方向に押し出して下ケースと上ケースを同じ形で切るので、前後の面は上下で1枚の平面になる（上ケースは凹みだけ。穴は凹みの内側に収まる）。ほかは埋める。寸法は `casegeo.py` の `SW_*`。
  - ガスケット溝は「タブの先端側の幅＋0.6mm（最低17mm）」×「本体の内側2mm〜本体＋4.2mm（外形の外まで抜ける）」。奥の広いタブ（17.6mm）だけ溝が18.2mmになる。
  - ゴム足（φ10）の凹みを、机側の面の四隅に4か所（`foot_d` 10.5、深さ `foot_t` 1）。空洞の上では床が1mm残る。
  - 床は傾斜に沿って厚さ `floor_t` 2mm（2026-10-06 に水平に変更。下の「床」）。PCBはガスケットで浮かせるので支柱は無し。MCU部の壁は下ケース（上面 `mcu_cover_z` 3.9）。
  - ガード（2026-10-03、旧 sage60-top-case と同じ考え方）：上ケースで、メインブロックの下と親指キーの間、右の列の下〜いちばん親指側のキー、右の壁沿いを塞ぐ。`casegeo.guard_region`（範囲は `GUARD_BOX` x≥94〜MCU部の手前、右は反転してトラックボールの穴と TB_ACCESS を除く。キーキャップ 18×18 の 5mm 未満の隙間を埋めてから＋`KEY_CLR` 1.0 を避け、角は R1.5、幅1.5mm 未満は捨て、リングに 0.4mm 食い込ませる）→ スケッチ `TOP_GUARD` を `guard_z`（MX 1.0 / ロープロ 0.5、プレートがガスケットで動くので浮かせる）から天面まで MOCK に足す。上ケースにつながらない島は作らない。
  - プレートは左右別（2026-10-10 ユーザー決定。2026-10-03〜09 は左プレートを右でも切り離して使う共通プレートだったが、FR4 でも金属でも切り離しが現実的でないためやめた）：左 `pcb/mx_left_plate/`、右 `pcb/mx_right_tb_plate/`（トラックボールまわりの親指キー2つと手前のタブが無い形）。それぞれ単独で発注する（ガーバーは `kicad-cli` で `production/<name>.zip`。層は Edge.Cuts だけで、マスク層は無い）。MX とロープロは同じプレート（1.2mm）。
  - 磁石用の切り欠き（2026-10-03、`mag_notch.py`、適用済み）：左 PCB とプレート（と右プレートの鏡像の位置）の右下の縁に半円の切り欠き（PCB r3.95＝柱＋0.3、プレート r4.65＝ボス＋1.0）。下ケースの柱と上ケースのボスがそこで合う。左 PCB はそのために ROW4 の裏面の配線を引き直した（(188.02,94.50)→(178.52,104.0)→ビア(176.05,104.0)→表面で (176.05,112.01)、D28 のパッド1へは古いビアから裏面で接続。DRC は変更前と同じ件数、未配線0、ゾーンは塗り直して保存）。右 PCB は変えていない。`sharp_pcb` は半径3より大きい円弧を切り欠きとして抜く。`geo.outline` は gr_poly / gr_circle（スロット・ミシン目）も読む。
  - スライドスイッチは 3ピンのスルーホール（2.54mm ピッチ。2026-10-14）。つまみは外壁（左ケースでは+x）を向く。
- 作り方（2026-10-02〜）：`mechanical/case/README.md`。`make_left.py` → `make_right.py` → `make_checkpts.py` で形をPythonで計算し、Fusion で `fusion/stage0〜3`（右は `stage4` も）を実行し、最後に `fusion/check.py` を実行する。stage0 でドキュメントを空にして作り直すので、Fusion上で手で直したものは消える。直すときはスクリプトを直す。
  - Fusionの座標：プレート上面が z=0、Fusion の y＝−KiCad の y。平面形状（外形・空洞・開口・溝・磁石・足・ネジの位置）はPythonが決め、Fusion のパラメータが決めるのは高さ方向と穴径。
  - フィレット：空洞（＝内壁）の角はスケッチ側で丸め済み。Fusion の `FILLET_INNER` は内壁以外の非接線の縦エッジ（磁石の穴は除く）に `inner_r`。
  - 検証（2026-10-02、左右とも0）：PCB・プレート（タブ込み）の内側の点が、下ケース・上ケース（MOCK_A）に入っていない。上下の重なりが0mm³。USBプラグの通り道（14.6×8.6）に材料が無い。右はトラックボールケースのSTL全頂点が入っておらず、底の頂点は234点中232点が座面に乗っている。
- 右側の差分（トラックボール）：
  - 右のPCB・プレート・XIAO・スライドスイッチは、左を x=122.92 で反転したもの（x' = 245.84 − x）。違うのはトラックボールまわりだけ：プレートの手前 x100〜189 が削られて前のタブが無い（タブ5つ）。PCBには J1（PMW3610の7ピン、KiCad (160.995,122.395)）用の舌が y −132.3 まで伸びる。傾斜軸の線は反転しない（向きで傾斜の向きが逆になるため）。
  - トラックボールケースは roBa の `trackballcase.stl`（git LFS、oid cdaa94d5…）。センサー窓がボール中心から (+25.94,+0.08) にあるので、ボール中心は Fusion (135.055,−122.475)。回転はしない（カップの低い側が手前左）。STL の z_rel → Fusion の z は −11.0。ケースの底が `TB_SEAT` = −(plate_t+pcb_gap+tb_gap+tb_leg_h) = −9.0 に来る。
  - 外形は「反転した左の外形」と「トラックボールケースの凸包」を合わせ、手前の辺を親指側の角の高さ（y −135.5）で1本の直線に切る（2026-10-02）。右手は親指クラスタとトラックボールに合わせて手前を出し、ケースでトラックボールを囲う（2026-10-04、上記）。`TB_POCKET` は棚から TB_SEAT まで掘る（R1.5、最小隙間0.37）。トラックボールケースは磁石2個で留める（2026-10-29 ユーザー決定。前は机側から M1.7 ネジ2本）：ケースのネジの耳 (144.645,−114.0) (144.645,−130.2) を r3.75・高さ 3.9 の円柱に太らせて φ6×3 を下から埋め込み（穴 φ6.1×3.1、ボールの穴まで最小 0.7。`tb_socket_cut.py`）、下ケースは座面から φ6.1×`tb_mag_h`（3.1）の穴に向かい合わせ（`TB_MAGS` / `TB_MAG_CUT`、極性は引き合う向き）。横はポケットで決まり、磁石は上に抜けるのを止めるだけ。ボールの支持球は非磁性（セラミック/ジルコニア）であること。
  - 上ケースの開口は「プレート本体＋open_clr」「キーキャップ＋KEY_CLR（5mm 未満の隙間は埋める）」をまとめて R1.5 で丸めたものと、トラックボール穴（個別に丸める。まとめて丸めるとセンサーの筒の部分がくびれで切れる）の和（2026-10-03）。トラックボールの奥（ボールの中心 y=TBY より奥）は削る：`TB_ACCESS`（左は親指クラスタの右辺＋`RIM` 5.5mm、右は x=168、手前は y=TBY）で上ケースを全部削り、下ケースは `TB_DECK` = −(shelf_d+`tb_deck_d`) = −4.0 まで下げる。ボールの中心より手前はケースでトラックボールケースを囲う（2026-10-04 ユーザー指示。前は ZaruBall と同じく手前を開放していてカップが前面から2.8mm出ていた）。右手の手前の外形は、親指クラスタとトラックボールに沿わせて余白を最小にした形（元の外形とトラックボールの包絡線（凸包）の和、凹の角は `FRONT_R` 4 で埋める。右の斜めの辺は凸包で1本に。トラックボールの前で MX 5.5mm、ロープロ 6.6mm 前に出る。トラックボールの所だけ段で出す形、手前全体を一直線に出す形、親指からトラックボールまで直線で結ぶ形を経て、ユーザーが「余白はできるだけ無くしたい」と判断（2026-10-04）。下ケースの壁 `THIN_BOT` 2mm 以上、上ケースは外壁込みで `THIN_TOP` 3mm 以上）。上ケースの開口はキーの穴とトラックボールの穴の2つのループ。2026-10-03 に一度 PCB の上を上ケースで覆ったが、トラックボールと4列目の間が 2〜4mm の細い帯になり造形が難しいので 2026-10-04 にやめた（そこは PCB の縁が見える。ユーザー了承）。トラックボールまわりは、削った後に残る上ケース 3mm 未満・下ケース 2mm 未満の部分を `make_right.py` が自動で削る（`THIN_TOP` / `THIN_BOT`。外形と切り欠きが鋭角で交わる右手前の角など）。`RIM` を 4→5.5 にしたのは、親指クラスタ脇の上ケースの縁がキーキャップの逃げで 3mm 未満になっていたため。右の外形は PCB から最低 2mm 外（ロープロで舌の角が 0.35mm はみ出していた）。
- 右PCBの舌（2026-10-04 修正済み、`tongue_edge.py`）：トラックボールケースの「[」脚の腕が舌の左の辺（x=158.0）と0.49mm重なっていたので、辺を x=158.9 へ（隙間0.36）。舌に沿う SDIO / MOTION の配線を0.32右へ（J1 のパッドまで0.2）。J1 は動かしていない。DRC は変更前と同じ件数。

## CNC 対応（2026-10-05、ユーザー指示「CNC の指摘は徹底的に直す。そこが一番重要」）
JLCCNC のガイドライン（https://jlccnc.com/help/article/CNC-Machining-Design-Guideline ）に合わせた。ここに書いたことは下の「決定事項」より優先する。
- ルール：縦の内角は R ≥ H/10 + 0.5（H＝その壁の高さ。`casegeo.cnc_r`）。壁は 0.8mm 以上（金属の推奨。`THIN`）。アンダーカット無し。段取りは2回：下ケースは「上からプレート面に垂直」と「下から机の面に垂直」、上ケースは「上から」と「下から（どちらもプレート面に垂直）」。
- 検証は `fusion/machinability.py`（B-Rep を直接調べる。①各面がどちらかの段取りの向きから見えるか（レイ）②工具の向きに平行な鋭い内角（削り残し＝R(1/cos(θ/2)−1) が 0.05mm を超えるもの）③縦の凹面の R と高さ ④穴の深さ ≤ 4D ⑤肉厚 0.8 未満）。結果は `cnc_<side><sfx>.json`。4ドキュメントとも全項目 0 を目標にする。
- Z の目安は `casegeo` の `desk_z / cav_depth / SKIRT_H / OUTER_H`（Fusion のパラメータと同じ値を Python にも持たせている）。
- 空洞：上ケースの開口（`TOP_RING_INNER`＝`inner`、R1.5 の逃げ付き）を含み、さらに深さに応じた R のドッグボーン（`casegeo.relieve`）を足したものを `CAVITY` にした（上下で別スケッチ。逃げはリングの下に隠れるので見た目は面一のまま）。磁石の柱には逃げを当てない（`forbid`）。
- 外形：MX は凸の角 `OUTER_R` 3.3（MCU 部では上ケースのスカートの内側が全高 約30mm になるため）、凹の角 `CONCAVE_R` 6（外壁がその外側 2.3mm にあり高さ 約31mm）。ロープロは 2.0 / 4.0。上ケース外壁の外面の凸の角は `WALL_OUT_R` 2.5（MX・ロープロとも。2026-10-14 ユーザー決定。公開されているアルミケースの実測：Keychron Q60 Max / Q11 R2.0、Bakeneko60 R2.25、JP01 R2.0、Lily58 Pro のアルミケース R3.0。旧 sage60-top-case は R3.25、2026-10-07〜14 は R4.0。外側の角は CNC の制約が無いので内側から切り離した。`casegeo.top_outer` → スケッチ `TOP_WALL` の外側 `TOP_WALL_OUTER`。凹の角は外から見ると内角なので `CONCAVE_R` のまま）。天面の外周に 0.5 の面取り（パラメータ `top_chamfer`、`fx.top_chamfer` → フィーチャー `TOP_CHAMFER`。天面と `TOP_WALL_OUTER` の面の稜線だけで、MCU カバーの下は除く。左は stage3、右は stage4 の最後）。
- USB とスライドスイッチ：横から削る形をやめ、平面のスケッチ（`USB_RECESS` `USB_RCPT` `SW_SCOOP` `SW_OPEN`）を各自の下端（`_slot_z`、パラメータの式）から上へ切る「上が開いた溝」にした。下ケースは MCU カバーが上を閉じる。上ケースは外壁に上から切り欠き（`USB_RECESS` `SW_SCOOP` だけ）。溝の奥の角は R2。`SW_OPEN` は 12→11mm（空洞の逃げと 0.7mm のくさびになっていた）。
- MCU 部：上ケースのリングを切る `TOP_MCU_OPEN` は四角のまま、外壁を足した後に付け根と内角を Fusion で R`inner_r` のフィレット（stage3 の `TOP_MCU_FILLET`）。下ケースの MCU の壁の範囲 `MCU_RING` はそれより `clr` 内側、角は R(1.5−clr)（同心で隙間 `clr`）。
- ガスケット溝：下ケース用 `GASKET_POCKET` は外壁の外まで抜く（`POCKET_OUT_B`＝本体＋16。奥は円弧で本体から 6mm 以上離れるため）、上ケース用 `TOP_GASKET_SLOT` はリングの中で止める（本体＋4.2）。角は R1（`POCKET_R`）。下ケース側の溝も磁石の位置決めで避ける。
- ガード：開口のうち R1.5 の工具が届かない所は全部ガードにし（付け根・細い隙間）、0.8 未満のひれは削る（`guard_fill`）。外壁沿いの幅 3mm 未満の帯は作らない（`GUARD_MIN` 3。2mm の帯がガスケット溝と薄肉を作っていた）。
- トラックボール：`TB_ACCESS` は上ケースの開口と合わせて逃げを付ける（外周の内側はリングの厚さ 8.2 なので R1.5）。`TB_POCKET` は空洞との合わせ目に逃げ。磁石穴 `TB_MAG_CUT` はポケットの底から上から掘る。
- 磁石：壁 `MAG_WALL` 0.6→0.8。切り欠きは PCB r4.45＋付け根 R2.0、プレート r5.15＋付け根 R1.0（`notch_fillet.py`、適用済み。柱の壁 0.8＋逃げ 0.3＋隙間）。左は「右下の切り欠き」「親指の段差（`MAG_STEP` 付近、足りない分だけ外形を直線で出す `casegeo.magnet_bump`）」「奥2」。右は「左の辺 A2（右 PCB にも切り欠きを新設。周り 7mm に銅は GND ベタだけ）」「右手前の角 B（`MAG_B`、外形を直線で出す。ユーザー了承）」「奥2」。
- 右手前の外形（2026-10-05 ユーザー指示「キーとトラックボールに沿ってキワキワ、曲線はトラックボールの所だけ」）：左の外形（磁石用の出っ張り前）＋トラックボールの包絡線（ボールの中心より手前は凸包）＋PCB＋3 を合わせ、凸包で一直線にそろえる処理はやめた。親指とトラックボールの間の凹みは直線で埋める（上ケースに細い帯が残るため）。
- トラックボール手前の枠（2026-10-05 ユーザー指示「枠は残し、トラックボールの手前で被っている上だけを若干削る」）：ボールの中心より手前で、上ケース（リング＋スカート）の天面を `tb_front_drop`（MX 7mm → 天面 z=0＝プレート上面、棚の上に1.2mm。2026-10-05「ほとんど露出するくらい」。ロープロ 1mm → z=1.0）下げる。範囲 `TB_FRONT_LOW`（`make_right.py`）は、TB_ACCESS の手前の2つの角から外形の左右の辺の外向き法線（`FRONT_N`）に沿って外壁の外まで引いた線の間（どちらの側も直角に交わり、くさびを作らない）。stage4 の `TB_FRONT_LOW_CUT`。2026-10-07（試作レビュー「親指とトラックボールの間の三角形が邪魔」）：左端は TB_ACCESS の角ではなく親指クラスタの右下の角（PCB (104.957,−117.72)）の 3mm 右から。角ちょうどだとキーの穴の縁とほぼ平行で 0.29mm のくさびになる。
- 床（2026-10-06 ユーザー指示「MX の床は水平、バッテリーの所以外は埋めてよい。吸音フォームは薄いので水平が良い」）：MX も床を水平にした（`cav_z` 11、ソケットの下端 −8.4 との間にフォーム用の 2.6mm。傾いた深い空洞 `CAVITY_DEEP` はやめた）。バッテリー（EEMB 552036、5.5×20×36、ロープロと同じ）と JST PH のポケット `BAT_POCKET` だけ `bat_z`（＝PCB の下にソケット・バッテリー・膨らみ代 0.5、14.4）まで掘る。位置は JST（左 PCB の Bluetooth1、KiCad (177.3〜186.0, 51.1〜58.1)、ケーブルは −x から）のすぐ左にバッテリーを横向き（`casegeo.battery_pocket`、余白 0.8 で R2 が角に当たらない）。ポケットの下の床は 4.8mm 以上。右はミラー。ロープロは今までどおり（空洞全体がバッテリーの深さ）。
- MCU カバー（2026-10-06）：ウォルナットで作る。発注は DXF（`mcu_cover_dxf.py` → `case/sage60_{left,right}{,_lp}_mcu_cover.dxf`、mm、上から見た Fusion の XY）。形は B 案（ユーザー決定）：上ケースの MCU の開口から外壁の外面まで覆う。MCU 部だけ上ケースの外壁の上端を `mcu_cover_z` まで下げ（stage3 `TOP_MCU_SKIRT_A`）、カバーはその上と下ケースの MCU の壁の上に載る。リングの端とは `COVER_CLR` 0.3、内角は TOP_MCU_FILLET と同心。厚さ `cover_t`：MX 3.0（天面より0.1低い）、ロープロ 1.2（天面と面一。木としては薄い）。留め方は上の「MCUカバーは磁石1個」（2026-10-24 にネジをやめた。DXF のレイヤー `RECESS_UNDERSIDE_0.6` が裏の鉄の円板の凹み）。ロープロのカバーは USB のレセプタクルとプラグが天面より上に出るので USB の溝の所を切り欠く。Fusion のボディは `MCU_COVER`（外観はウォルナット）。
- 右 PCB の J1 の舌（2026-10-06、`tongue_trim.py`）：トラックボールのセンサー基板が PCB に少し当たったので、舌の左の辺（トラックボール側）を 158.9→159.9 に削った（J1 とトラックボールの位置は変えない）。J1 のパッドと辺の間は 0.245（JLC の 0.2 以上）。左の辺沿いの SDIO / MOTION は J1 の右側へ（SDIO は表面で外側、MOTION は内側を通ってビアで裏面から7番ピンへ）。表面の GND ベタが J1 の3番ピンでしか裏面とつながっていなかったので、GND のステッチビアを2つ足した。DRC は変更前と同じ 351 件、未配線 0。

- トラックボールの座面は −6.2。磁石穴の下の肉は 3.8mm（MX は 1.6 / 3.6mm）。
- 外形（上ケース外壁込み）145.3×123.1（MX 147.5×125.5）。
- 検証（2026-10-03、左右とも0）：PCB・プレート・ソケット下端・JST・21×40×6.0 のバッテリーの箱・USB・スライドスイッチ・上下の重なり・トラックボールケース（座面に乗る底の点 226/234）。

- MCU 部の台（2026-10-06 ユーザー指示「LP の USB の切り欠きが微妙」、案①）：LP は `mcu_cover_z` 0.8 → 4.8。下ケースの MCU の壁と、上ケースの外壁の MCU 部（`TOP_MCU_BLOCK`＝TOP_WALL を top_h〜mcu_cover_z、`TOP_MCU_OPEN` で切る）を伸ばした天面より一段高い台にし、カバー `cover_t` 2.5（上面 +7.3）を載せる。USB ケーブルの成形部の上端 +4.3 より上なので、カバーに USB の切り欠きは無い（背面は四角い穴）。台の高さで外形の凸の角に R が要るので LP の `OUTER_R` 2.0 → 2.1（`OUTER_H` は台の上から）。XIAO を PCB 裏に移す案②はユーザーが見送り。
- MCU カバー：内側の辺は隣のキーキャップ＋`KEY_CLR` 1mm を避ける（キーキャップは MCU の開口の上へ最大 3.7mm はみ出す。`mcu_cover(..., caps)`、入り隅 R1）。カバーは `check.py`（壁に載っているか `cover seat gap` 0）と `check_parts.py`（部品との干渉）で調べる。SW32 の仮のピンヘッダのモデル（ピンが 8.5mm 上に出る）が LP のカバーに 1.9mm³ 当たるが、カバーの下面は PCB 上面から 7mm 上なので、普通のスライドスイッチなら当たらない。
- 上ケースは A案（スカートを机まで下ろし、下端も傾斜で切る）で確定（2026-10-03）。案B（MOCK_B、`skirt_b`）は作らない。上ケースのボディ名は `MOCK_A` のまま。

## ルール
- 試作は3Dプリントで行うが、最終的には JLCPCB の CNC で作る前提で設計する。
  - アンダーカットを作らない。
  - 内角には工具半径以上のR（目安R1.5以上）をつける。
  - 薄い壁や、深くて細い溝を避ける。
  - 表裏2回までの段取りで削り切れる形にする。
- 寸法はすべてユーザーパラメータにする（傾斜角、ガスケット厚、嵌め合いクリアランス、壁厚、磁石穴、内角R）。
- ガスケット：タブの上下に貼る。下ケース棚と上ケースのリング下面の両方に、タブ位置で溝（`gasket_pocket` 1mm、スケッチ `GASKET_POCKET`）。上ケースの開口はプレート本体＋`open_clr` で、タブの上は塞ぐ。上ケースのモックは TOP_RING（開口と CASE_OUTER＋`clr`）と TOP_WALL（CASE_OUTER＋`clr` 〜 ＋`clr`+`wall`）から作る。フィーチャーは TOP_RING_x → TOP_MCU_OPEN_x → TOP_GASKET_SLOT_x → TOP_MAG_x → TOP_WALL_x（Bは −skirt_b、Aは DESK_PLANE まで）→ TOP_USB_x → SW_SCOOP_CUT_x。上下の合わせ面（棚の上面＝リングの下面）は `shelf_d`（＝`plate_t`、プレート下面）。
- 仮の値：ガスケット厚はタブの上下とも 1.5mm、クリアランス 0.3mm、外壁 2mm。確定したらこのスキルを更新する。

## 進め方
1. 設計する順番は `sage60_left_bottom` → `sage60_left_top` → 右側。左右とも `mechanical/case/` のスクリプトで作る（右は左を反転して、トラックボールまわりの差分を足す）。
2. プレート・PCBの外形は KiCad の Edge.Cuts から取る（スクリプトが読む）。
3. 段階ごとにスクリーンショットを撮って、ユーザーに確認を取ってから次に進む。
   - モック・ケースの画像は必ず PCB と部品（XIAO・ソケット・JST など）とスイッチ・キーキャップを入れて撮る（2026-10-03 ユーザー指示）。スイッチは MX が Cherry MX、ロープロが Kailh Choc（v1 のモデルで代用）。キーキャップは `fusion/keycap.py` の簡易な台形の箱（MX 7.5mm、ロープロ 3.5mm）。`pcb_step.py` で書き出した STEP を `fusion/stage5.py` が `PCB_REF` として読み込む（stage0 で消えるので作り直すたびに実行する）。部品・スイッチ・キーキャップ（押し込み時も）とケースの干渉は `fusion/check_parts.py`（2026-10-03、4つとも0）。平面図などの Python の図にも PCB・プレートの外形を描く。
   - 画像はチャットに添付できないことがあるので、そのときは Mac で `open` して見せる。形が変わる操作をしたら、干渉チェック（pointContainment など）で検証する。
4. 参照用の旧プロジェクトは `sage60-top-case` v29。上ケースの外形は約141×129×34mm、下ケースは約137×123×25mmで、7°傾斜、x=0でミラー。
5. 構造やルールが変わったら、このスキルと設計資料のArtifactを更新する。
